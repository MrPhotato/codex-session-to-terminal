修复 Desktop 自动更新后无法启动共享会话的问题。

- 不再要求 Desktop 与预设的完整版本号一致，普通更新无需手动改版本号。
- 每次启动都发现当前 Desktop 包和内置后台程序，自动刷新安装路径与原生转发器。
- 分别检查后台的 WebSocket / 鉴权参数和终端的远程连接参数，随后验证实际连接及会话列表接口。
- 检查失败会报告具体原因，不关闭正在运行的 Desktop，也不删除聊天或账号数据。

请先完成当前任务并正常退出 ChatGPT，再从开始菜单打开 **Codex Session to Terminal**。首次安装仍需联网下载固定版本的终端 CLI；后台使用当前 Desktop 自带的程序。快捷键仍为 **Ctrl+Alt+L**。

Windows x64，按当前用户安装，无需管理员权限。安装包自带 Node.js 24.22.0 和 PowerShell 7.6.5；独立终端 CLI 为 0.163.0-alpha.10.2。卸载保留私人连接数据及 ChatGPT 账号和历史。

安装包尚未代码签名，Windows 可能显示“未知发布者”。同页提供 SHA256 校验文件。

本版在 Desktop 26.1013.4894.0 上验证了组件能力和隔离连接；完整桌面会话还需通过用户下一次共享启动验证。非官方 Preview，未来实际接口变化仍可能需要适配。
